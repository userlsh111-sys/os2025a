1. git init: 깃 등록
2. 커밋'러' 등록: git config --global user.email "(메일)", git config --global user.name "(이름)"

3. git add (파일): 커밋 장전(.으로 다 할 수도 / git status로 확인)
4. git commit -m "(커밋명)"
5. 커밋 확인: git log, git log --oneline
6. 커밋 구경: git checkout (해시코드)
7. 커밋명 변경: git commit --amend -m "(새 커밋명)"
8. 커밋 이동
-git reset --hard 'HEAD~num'
-뒤로 num까지의 커밋 제거
-불가: 최초 커밋, ^(캐럿 기호 in 파워셸)
-num은 자연수, hard로 파일도 그 커밋 전 상태로.

9. 원격 첫 추가: git remote add (원격명) (URL)
10. 원격 확인: git remote -v

11. 원격의 브랜치(파일들) 가져오기
-default만: git clone (URL)
-git clone -b (원격 브랜치명) --single-branch (URL)
-뒤에 (폴더명) 붙여서 폴더명 지정할 수 있음.
-모든 브랜치를 한꺼번에 가져올 순 없음.
-init 안 해도 됨.
12. 원격명 변경: git remote rename (old) (new)
13. 원격 삭제: git remote remove (원격명)

14. 브랜치명 변경: git branch -m (새 브랜치명)
15. 브랜치 삭제: git push (원격명) --delete (기존 브랜치명)

16. 파일 혹은 폴더명 변경
-git mv (기존 명칭) (새 명칭)
-파일은 '.형식'도 포함할 것.
17. 깃으로 삭제
-파일: git rm (지울 파일명.형식)
-폴더: git rm -r (지울 폴더명 / 강제시 앞에 -f도 띄어붙일 것)

18. 로컬을 원격에 일치: git pull (원격명) (브랜치명)
19. 원격을 로컬에 일치
-git push -u (원격명) (브랜치명)
-강제로 할 거면 뒤에 -f도.
-한 번만 하면 git push까지만 하면 됨.


번외(1). 기존 (init한)깃 삭제: git rm --cached (대상 폴더)
-이거 없이 다른 init 폴더에 넣기만 하고 push하면, 깃허브에 subproject라고만 뜸. 

번외(2). 원격 브랜치명 변경: 직접 바꿀 순 없음. 
-1. 로컬의 clone 브랜치명 변경
-2. 원격으로 push, 새 브랜치 생성
-3. 기존 원격 브랜치 삭제

번외(3). 프로젝트 후 내 리포짓으로 복사(파일, 역사)
-1. git remote add로 팀과 나의 원격 추가
-2. git fetch (팀 원격): 팀 리포짓의 파일 정보와 역사(커밋들) 가져옴. 소스 코드 가져오는 건 아님. 
-3. git merge (팀 리포짓)/(그 중 한 브랜치) --allow-unrelated-histories: 에러 안 나도록 합침. 이제 보임. 
--복잡하니 브랜치 단위로 최상위 폴더 만들 것. 
-4. git push -u (내 원격) (해당 브랜치) -f




<Linux 일부>

2. 파일 만들기

-echo "(내용)" >> (파일)

3. 내용 보기: cat (파일)
4. cd: change directory(.은 하위, ..은 상위)
